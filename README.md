# Usman Anwar — Professional Portfolio

An international-client focused full-stack engineering portfolio built with React, TypeScript, Vite, Framer Motion and React Icons.

## Run locally

```bash
npm install
npm run dev
```

## Create a production build

```bash
npm run build
```

The optimized site is generated in `dist`. The portfolio includes a downloadable CV, responsive layouts, real technology icons, scroll animation, 3D project interactions and accessible reduced-motion support.
